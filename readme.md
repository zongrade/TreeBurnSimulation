## Возможности

- 🌱 **Рост деревьев** — случайное появление и рост высоты, независимо от соседей
- ⚡ **Молнии** — удары по распределению Пуассона, выбирают самое высокое дерево в радиусе
- 🔥 **Пожары** — распространение от горящих соседей с настраиваемым радиусом
- ⏱ **Реальное время** — фиксированный simulation tick и независимый render FPS
- 🧵 **Параллельность** — чанки и пул воркеров, double buffering без гонок данных
- 🖥 **UI-панель** — кнопки управления, статистика, логи прямо в окне
- 📸 **Скриншоты и видео** — автосохранение кадров и сборка MP4 через ffmpeg
- 📈 **Адаптивная запись** — при крупных пожарах кадры сохраняются чаще

## Как это устроено

### Модель клетки

Отдельного `state` нет — всё выводится из двух массивов:

| `Heights[i]` | `Burns[i]` | Состояние клетки                  |
| ------------ | ---------- | --------------------------------- |
| `0`          | `0`        | пусто                             |
| `> 0`        | `0`        | живое дерево                      |
| `> 0`        | `> 0`      | горит (осталось `Burns[i]` тиков) |

### Порядок тика

```
1. Молнии          → поджигают деревья в текущем буфере
2. Параллельный апдейт → читаем Current, пишем Next (по чанкам)
3. Swap буферов    → Next становится Current
4. Пересчёт статистики
```

Все клетки принимают решения по состоянию **на начало тика**, поэтому возгорание действует со следующего тика. Это даёт детерминированность и отсутствие data race.

### Распространение огня

Клетка суммирует «вес» горящих соседей:

- ортогональный сосед → `100`
- диагональный сосед → `100 * DiagonalFactor`
- дальний сосед (при `SpreadRadius > 1`) → `DiagonalFactor * 50`

Вероятность возгорания:

```
p = 1 - exp(-SpreadRatePerSecond * weight / 100 * dt)
```

Время горения зависит от высоты:

```
burnTicks = BurnBaseTicks + height * BurnTicksPerHeight
```

## Требования

- **Go 1.21+**
- **ffmpeg** — только для сборки видео (проверяется при старте, без него симуляция работает)
- Linux: системные зависимости Ebiten (`X11`/`Wayland`, `OpenGL`)

## Управление

### Мышь

| Действие                  | Результат                |
| ------------------------- | ------------------------ |
| Колесо мыши               | Зум к точке под курсором |
| Средняя кнопка + движение | Перетаскивание карты     |

### Клавиатура

| Клавиша                   | Действие                              |
| ------------------------- | ------------------------------------- |
| `W` `A` `S` `D` / стрелки | Перемещение камеры (с инерцией)       |
| `Shift`                   | Ускорение ×5                          |

| `R`                       | Сброс камеры                          |
| `F1`                      | Показать/скрыть отладочную информацию |
| `F2`                      | Сохранить скриншот                    |

Камера работает только когда курсор находится над областью симуляции (правее панели).

## Конфигурация

Все параметры живут в `sim/config.go` и переопределяются в `main.go`.

### Мир и параллельность

| Параметр           | Значение по умолчанию    | Описание                    |
| ------------------ | ------------------------ | --------------------------- |
| `Width` / `Height` | `1000` / `1000`          | Размер поля в клетках       |
| `TickRate`         | `10`                     | Тиков симуляции в секунду   |
| `WorkerCount`      | `12`                     | Число воркеров              |
| `ChunkSize`        | `64`                     | Размер чанка в клетках      |
| `Scheduler`        | `SchedulerDynamicChunks` | Режим распределения работы  |
| `Seed`             | `42`                     | Сид для детерминированности |

### Рост

| Параметр                    | Значение   | Описание                          |
| --------------------------- | ---------- | --------------------------------- |
| `Growth.SpawnRatePerSecond` | `0.000005` | Появление дерева на пустой клетке |
| `Growth.GrowRatePerSecond`  | `0.02`     | Прирост высоты на `+1`            |
| `Growth.MaxHeight`          | `255`      | Максимальная высота               |

### Молнии

| Параметр                     | Значение | Описание                             |
| ---------------------------- | -------- | ------------------------------------ |
| `Lightning.StrikesPerSecond` | `0.3`    | Среднее число ударов в секунду       |
| `Lightning.Radius`           | `2`      | Радиус поиска самого высокого дерева |

### Пожар

| Параметр                   | Значение | Описание                                     |
| -------------------------- | -------- | -------------------------------------------- |
| `Fire.SpreadRatePerSecond` | `0.7`    | Базовая скорость распространения             |
| `Fire.DiagonalFactor`      | `0.7`    | Множитель диагональных соседей               |
| `Fire.SpreadRadius`        | `1`      | Радиус распространения (`1` = только соседи) |
| `Fire.BurnBaseTicks`       | `20`     | Базовая длительность горения                 |
| `Fire.BurnTicksPerHeight`  | `0.5`    | additional тиков за единицу высоты           |

### Сохранение

| Параметр                    | Значение      | Описание                                    |
| --------------------------- | ------------- | ------------------------------------------- |
| `Save.Enabled`              | `false`       | Включить автосохранение                     |
| `Save.EveryTicks`           | `100`         | Интервал обычных скриншотов                 |
| `Save.Dir`                  | `screenshots` | Корневая папка                              |
| `Save.FilenameDigits`       | `6`           | Число нулей в имени (`000001.jpg`)          |
| `Save.Format`               | `FormatJPEG`  | `FormatJPEG` или `FormatPNG`                |
| `Save.Quality`              | `85`          | Качество JPEG, `0–100`                      |
| `Save.LogToFile`            | `true`        | Писать лог в `simulation.log`               |
| `Save.VideoFramerate`       | `30`          | Частота кадров итогового видео              |
| `Save.AdaptiveEnabled`      | `true`        | Адаптивная частота записи                   |
| `Save.FireThreshold`        | `100`         | Абсолютный порог крупного пожара            |
| `Save.FirePercentThreshold` | `0.05`        | Процентный порог (если `FireThreshold = 0`) |
| `Save.EveryTicksOnFire`     | `10`          | Интервал скриншотов при крупном пожаре      |

Обычные скриншоты пишутся **всегда**. Адаптивные добавляются **сверху** при крупном пожаре; если оба совпадают в одном тике — сохраняется один кадр.

### Пример настройки в `main.go`

```go
cfg := sim.DefaultConfig()

cfg.Width = 1000
cfg.Height = 1000
cfg.Fire.SpreadRadius = 2
cfg.Save.Enabled = true
cfg.Save.Format = sim.FormatJPEG
cfg.Save.Quality = 85

world := sim.NewWorld(cfg)
world.FillTrees(0.3)
```

## Результат работы

Каждый запуск создаёт отдельную папку сессии:

```
screenshots/
└── sim_2026-08-08_14-30-22_seed42/
    ├── 000001.jpg
    ├── 000002.jpg
    ├── ...
    ├── simulation.log
    └── output.mp4
```

Видео `output.mp4` создаётся по кнопке **«Finish & Make Video»** (после этого приложение закрывается).

### Пересобрать видео из прошлой сессии вручную

```bash
ffmpeg -framerate 30 \
  -i "screenshots/sim_2026-08-08_14-30-22_seed42/%06d.jpg" \
  -c:v libx264 -pix_fmt yuv420p -crf 18 -y output.mp4
```

## Планировщики

| Режим                    | Статус      | Описание                                               |
| ------------------------ | ----------- | ------------------------------------------------------ |
| `SchedulerDynamicChunks` | ✅ работает | Пул воркеров забирает чанки из очереди                 |
| `SchedulerStaticStripes` | 🚧 заглушка | Статические горизонтальные полосы на воркер            |
| `SchedulerMainSMT`       | 🚧 заглушка | Основные чанки по физическим ядрам + подзадачи для SMT |

Заглушки пока вызывают `DynamicChunks`.
